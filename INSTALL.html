WINDOWS INSTALLATION GUIDE v1.0.0

ติดตั้ง Montien Tech Terminal บน Windows

คู่มือติดตั้งแบบ step-by-step สำหรับ Windows 10 / 11 รัน Node.js server บนเครื่อง Windows แล้วเปิดใช้งานผ่านเบราว์เซอร์

Windows 10 / 11 Node.js LTS npm Git (optional) PM2 (optional)
01 — ภาพรวมก่อนเริ่ม

แอปนี้ทำอะไร?

Montien Tech Terminal คือ SSH Client ที่รันเป็น Node.js server บน Windows แล้วเปิดผ่าน browser เพื่อ SSH เข้าเครื่อง Linux/Mac อื่น

ตัวแอปไม่ได้ SSH เข้า Windows — แต่ใช้ Windows เป็น relay server เพื่อเชื่อมต่อไปยัง SSH server ปลายทาง

Requirements

  • 🪟Windows 10 (Build 1903+) หรือ Windows 11
  • 🟢Node.js v18 LTS ขึ้นไป
  • 📦npm (ติดมากับ Node.js อัตโนมัติ)
  • 🌐Browser: Chrome, Edge, Firefox (รุ่นใหม่)
  • 🔐SSH server ปลายทางที่จะเชื่อมต่อ (เปิด port 22)

02 — ขั้นตอนติดตั้ง (Step-by-Step)

Step 1 — ติดตั้ง Node.js

ดาวน์โหลด Node.js LTS จากเว็บไซต์ทางการ แล้วติดตั้งตามขั้นตอนปกติ

  1. ไปที่เว็บไซต์ Node.js

    เปิด browser แล้วพิมพ์ใน address bar: https://nodejs.org

  2. ดาวน์โหลด LTS version

    กดปุ่ม "Download Node.js (LTS)" — ปุ่มซ้ายที่มีป้าย Recommended For Most Users

  3. รัน Installer (.msi)

    ดับเบิลคลิกไฟล์ node-vXX.XX.X-x64.msi ที่ดาวน์โหลดมา กด Next → Next → Install → Finish

  4. ตรวจสอบการติดตั้ง

    เปิด Command Prompt หรือ PowerShell แล้วพิมพ์:

    C:\Users\You> node --version
    v22.13.0
    C:\Users\You> npm --version
    10.9.2

    ถ้าแสดงเวอร์ชัน = ติดตั้งสำเร็จ

ℹ วิธีเปิด Command Prompt: กด Win + R พิมพ์ cmd แล้วกด Enter หรือค้นหา "Command Prompt" ใน Start Menu

Step 2 — ดาวน์โหลดโปรเจค

เลือกวิธีดาวน์โหลดตามความถนัด

วิธี A — Git Clone
วิธี B — Download ZIP

วิธี A — Git Clone (แนะนำ ถ้ามี Git)

ถ้ายังไม่มี Git ดาวน์โหลดได้ที่ https://git-scm.com

# เปิด Command Prompt แล้วพิมพ์
git clone https://github.com/<your-username>/ssh-screen.git
cd ssh-screen

วิธี B — Download ZIP (ไม่ต้องติดตั้ง Git)

  1. ไปที่หน้า GitHub repository
  2. กดปุ่ม Code (สีเขียว) → Download ZIP
  3. Extract ZIP ไปยังโฟลเดอร์ที่ต้องการ เช่น C:\ssh-screen
  4. เปิด Command Prompt แล้ว cd เข้าไปในโฟลเดอร์นั้น
# ตัวอย่าง ถ้า extract ไปที่ C:\ssh-screen
cd C:\ssh-screen

Step 3 — ติดตั้ง Dependencies

รันคำสั่งนี้ใน Command Prompt ภายในโฟลเดอร์โปรเจค:

C:\ssh-screen> npm install

npm จะดาวน์โหลดและติดตั้ง packages ที่จำเป็น:

added 87 packages in 12s
3 packages are looking for funding
✓ express ✓ ws ✓ ssh2
⚠ ข้อควรรู้: ระหว่าง npm install อาจมีข้อความเตือนสีเหลือง (WARN) ปรากฏขึ้น — ไม่เป็นอะไร ให้ดูว่าไม่มี ERROR ก็เพียงพอ

Step 4 — เริ่มรันเซิร์ฟเวอร์

C:\ssh-screen> npm start

ถ้าสำเร็จจะขึ้น:

✓ Web SSH Client server is running on http://localhost:3000
✓ เซิร์ฟเวอร์รันอยู่! อย่าปิด Command Prompt window นี้ — ถ้าปิด server จะหยุดทำงาน

ถ้าต้องการเปลี่ยน port จาก 3000 เป็นอื่น:

# PowerShell
$env:PORT=8080; node server.js

# Command Prompt
set PORT=8080 && node server.js

Step 5 — เปิดเบราว์เซอร์

เปิด Chrome, Edge, หรือ Firefox แล้วไปที่:

http://localhost:3000

หน้า Montien Tech Terminal จะโหลดขึ้นมา พร้อมใช้งานทันที

ℹ เข้าจากอุปกรณ์อื่นในเครือข่ายเดียวกัน: หา IP ของ Windows ด้วยคำสั่ง ipconfig แล้วใช้ http://<IP>:3000 แทน localhost (เช่น http://192.168.1.50:3000)

Step 6 — เชื่อมต่อ SSH

กรอกข้อมูล SSH server ในแผงด้านซ้าย แล้วกด เชื่อมต่อ SSH

  • 🖥Address — IP หรือ hostname ของ SSH server (เช่น 192.168.1.100)
  • 👤Username — ชื่อผู้ใช้บน server (เช่น root หรือ ubuntu)
  • 🔢Port — default คือ 22
  • 🔑Password — รหัสผ่าน SSH
03 — Windows Firewall

🔥 อนุญาต Port 3000 ผ่าน Firewall

ถ้าต้องการให้อุปกรณ์อื่นในเครือข่ายเข้าถึงได้ ต้องเพิ่ม rule ใน Windows Defender Firewall

  1. เปิด Windows Defender Firewall

    กด Win + S ค้นหา "Windows Defender Firewall" → เปิด

  2. เพิ่ม Inbound Rule ใหม่

    คลิก Advanced settings → Inbound Rules → New Rule...

  3. ตั้งค่า Rule

    เลือก Port → TCP → Specific local ports: 3000 → Allow the connection → ตั้งชื่อ เช่น SSH Terminal

⚠ ทางเลือกที่เร็วกว่า: รันคำสั่งนี้ใน PowerShell (Run as Administrator): 
New-NetFirewallRule -DisplayName "SSH Terminal" -Direction Inbound -Protocol TCP -LocalPort 3000 -Action Allow
04 — รันตลอดเวลา (Optional: PM2)

🔄 ใช้ PM2 ให้รัน Background และ Auto-Start

โดย default ถ้าปิด Command Prompt — server จะหยุด ใช้ PM2 เพื่อให้รัน background และเริ่มอัตโนมัติเมื่อ Windows เปิด

  1. ติดตั้ง PM2 แบบ global 
    npm install -g pm2
  2. ติดตั้ง pm2-windows-startup

    เพื่อให้ PM2 เริ่มอัตโนมัติเมื่อ Windows boot

    npm install -g pm2-windows-startup
pm2-startup install
  3. เริ่มรัน server ด้วย PM2 
    cd C:\ssh-screen
pm2 start server.js --name ssh-terminal
  4. บันทึก process list 
    pm2 save

    PM2 จะจำ process นี้และเริ่มใหม่อัตโนมัติเมื่อ Windows reboot

คำสั่ง PM2 ที่ใช้บ่อย

# ดูสถานะทั้งหมด
pm2 status

# ดู log realtime
pm2 logs ssh-terminal

# Restart
pm2 restart ssh-terminal

# หยุด
pm2 stop ssh-terminal

# ลบออกจาก PM2
pm2 delete ssh-terminal
05 — แก้ไขปัญหาที่พบบ่อย

❌ node / npm ไม่รู้จัก (command not found)

  • 🔄ปิดแล้วเปิด Command Prompt ใหม่หลังติดตั้ง Node.js
  • 🔍ตรวจสอบว่า Node.js อยู่ใน PATH: where node
  • ⚙ถ้ายังไม่ได้ ติดตั้ง Node.js ใหม่แล้วติ๊ก "Add to PATH" ในขั้นตอน installer

❌ Port 3000 ถูกใช้งานอยู่แล้ว (EADDRINUSE)

  • 🔍หา process ที่ใช้ port นั้น: netstat -ano | findstr :3000
  • 🔧เปลี่ยน port: set PORT=8080 && node server.js

❌ npm install ล้มเหลว / Error ตอนติดตั้ง ssh2

  • 🔨ติดตั้ง Windows Build Tools: npm install -g windows-build-tools (ใน PowerShell Admin)
  • 📥หรือติดตั้ง Visual C++ Build Tools จาก Visual Studio Installer

❌ เปิด Browser แล้ว "This site can't be reached"

  • ▶ตรวจสอบว่า npm start ยังรันอยู่ใน Command Prompt
  • 🌐ใช้ http:// ไม่ใช่ https://
  • 🔢ใช้ port ที่ถูกต้อง default คือ :3000

❌ เชื่อมต่อ SSH ไม่ได้จากเครื่องอื่น

  • 🔥ตรวจสอบ Windows Firewall ว่าเปิด port 3000 แล้ว (ดู Section 03)
  • 🌐ใช้ IP จริงของเครื่อง Windows ไม่ใช่ localhost (ดู ipconfig)
  • 📡ตรวจสอบว่าทั้งสองเครื่องอยู่ในเครือข่ายเดียวกัน
06 — Quick Reference

สรุปคำสั่งทั้งหมด

# ตรวจสอบ Node.js
C:\> node --version
C:\> npm --version

# ดาวน์โหลดโปรเจค (ถ้าใช้ Git)
C:\> git clone https://github.com/<user>/ssh-screen.git
C:\> cd ssh-screen

# ติดตั้ง dependencies
C:\ssh-screen> npm install

# รัน server (ปกติ)
C:\ssh-screen> npm start

# รัน server บน port อื่น (PowerShell)
PS C:\ssh-screen> $env:PORT=8080; node server.js

# รัน background ด้วย PM2
C:\ssh-screen> npm install -g pm2 pm2-windows-startup
C:\ssh-screen> pm2-startup install
C:\ssh-screen> pm2 start server.js --name ssh-terminal
C:\ssh-screen> pm2 save

# เปิดแอปในเบราว์เซอร์
http://localhost:3000
⚠ Security: อย่า expose port 3000 ออก internet โดยตรง แนะนำให้ใช้เฉพาะภายใน private network หรือ VPN เท่านั้น
